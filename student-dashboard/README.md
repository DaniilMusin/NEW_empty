# Личный кабинет ученика

Современный личный кабинет для учеников с минималистичным дизайном и интеграцией AI-ассистента на базе Perplexity.

## Возможности

- **📅 Расписание** - Создавайте и управляйте расписанием занятий
- **📝 Домашние задания** - Отслеживайте домашние задания с приоритетами и сроками
- **📊 Оценки** - Ведите учет оценок с автоматическим расчетом среднего балла
- **📋 Отчеты по занятиям** - Создавайте подробные отчеты о пройденных занятиях
- **🤖 AI-Ассистент** - Получайте помощь в учебе через интеграцию с Perplexity AI

## Технологии

- **Next.js 15** - React фреймворк для production
- **TypeScript** - Типизированный JavaScript
- **Tailwind CSS** - Utility-first CSS framework
- **Perplexity API** - AI-ассистент для помощи в учебе
- **LocalStorage** - Локальное хранение данных

## Установка и запуск

### Предварительные требования

- Node.js 18+
- npm или yarn

### Шаги установки

1. Клонируйте репозиторий или используйте существующую папку:

```bash
cd student-dashboard
```

2. Установите зависимости:

```bash
npm install
```

3. Создайте файл `.env.local` на основе `.env.local.example`:

```bash
cp .env.local.example .env.local
```

4. Получите API ключ Perplexity:
   - Зарегистрируйтесь на https://www.perplexity.ai/
   - Перейдите в Settings → API
   - Создайте новый API ключ
   - Добавьте ключ в `.env.local`:

```env
PERPLEXITY_API_KEY=your_actual_api_key_here
```

5. Запустите проект в режиме разработки:

```bash
npm run dev
```

6. Откройте браузер и перейдите по адресу:

```
http://localhost:3000
```

## Использование

### Расписание

1. Перейдите во вкладку "Расписание"
2. Нажмите кнопку "+ Добавить"
3. Заполните данные о занятии:
   - Предмет
   - Преподаватель
   - День недели
   - Время начала и окончания
   - Кабинет (необязательно)
4. Нажмите "Сохранить"

### Домашние задания

1. Перейдите во вкладку "Домашние задания"
2. Нажмите "+ Добавить"
3. Укажите:
   - Предмет
   - Название задания
   - Описание
   - Срок выполнения
   - Приоритет (низкий/средний/высокий)
4. Отмечайте выполненные задания галочкой

### Оценки

1. Перейдите во вкладку "Оценки"
2. Добавьте новую оценку:
   - Предмет
   - Тип работы (ДЗ, тест, экзамен, контрольная, проект)
   - Оценка и максимальный балл
   - Дата
   - Описание
3. Система автоматически рассчитает средний балл

### Отчеты по занятиям

1. Сначала добавьте расписание
2. Перейдите во вкладку "Отчеты"
3. Выберите предмет из расписания
4. Укажите дату, тему занятия и заметки
5. Отметьте присутствие/отсутствие

### AI-Ассистент

1. Перейдите во вкладку "AI-Ассистент"
2. Задайте вопрос ассистенту
3. Получите помощь с учебой, объяснения сложных тем
4. История чата сохраняется локально

## Хранение данных

Все данные хранятся локально в браузере с помощью `localStorage`:

- Расписание
- Домашние задания
- Оценки
- Отчеты по занятиям
- История чата с AI

**Важно:** Данные не синхронизируются между устройствами и будут удалены при очистке данных браузера.

```bash

# Запуск production сборки

# Проверка кода (ESLint)
```

### Добавление новых функций

1. Создайте новый компонент в папке `components/`
2. Добавьте необходимые типы в `types/index.ts`
3. Обновите `lib/storage.ts` для работы с новыми данными
4. Добавьте компонент на главную страницу в `app/page.tsx`

## Настройка темной темы

Приложение автоматически переключается между светлой и темной темой в зависимости от настроек системы.

Цвета темы настраиваются в файле `app/globals.css`:
- Светлая тема: `:root`
- Темная тема: `@media (prefers-color-scheme: dark)`

## Безопасность

- API ключ Perplexity хранится в переменных окружения
- Никогда не коммитьте файл `.env.local` в Git
- Используйте `.env.local.example` как шаблон
