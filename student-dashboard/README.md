# Личный кабинет ученика - Многопользовательская платформа

Современная многопользовательская платформа для учеников с минималистичным дизайном, системой аутентификации и интеграцией AI-ассистента на базе Perplexity.

## Возможности

### Для учеников:
- **📅 Расписание** - Управление расписанием занятий по дням недели
- **📝 Домашние задания** - Отслеживание заданий с приоритетами, сроками и статусами
- **📊 Оценки** - Учет оценок с автоматическим расчетом среднего балла
- **📋 Отчеты по занятиям** - Детальные записи о пройденных занятиях
- **🤖 AI-Ассистент** - Помощь в учебе через интеграцию с Perplexity AI

### Для администраторов:
- **⚙️ Админ-панель** - Управление учениками
- **➕ Создание учеников** - Генерация логинов и паролей
- **👥 Управление доступом** - Просмотр списка всех учеников
- **🔐 Безопасность** - Каждый ученик видит только свои данные

## Технологии

- **Next.js 15** - React фреймворк с App Router
- **TypeScript** - Типизированный JavaScript
- **Tailwind CSS** - Utility-first CSS framework
- **Supabase** - Backend as a Service (база данных + аутентификация)
- **Perplexity API** - AI-ассистент для помощи в учебе
- **Row Level Security** - Защита данных на уровне базы данных

## Установка и настройка

### Предварительные требования

- Node.js 18+
- npm или yarn
- Аккаунт Supabase (бесплатный план подходит)
- API ключ Perplexity (опционально)

### Быстрый старт

1. **Клонируйте репозиторий:**

```bash
cd student-dashboard
```

2. **Установите зависимости:**

```bash
npm install
```

3. **Настройте Supabase:**

Следуйте подробной инструкции в файле [SUPABASE_SETUP.md](./SUPABASE_SETUP.md)

Краткая версия:
- Создайте проект на https://supabase.com
- Скопируйте Project URL и anon key
- Выполните SQL из файла `supabase-schema.sql`
- Создайте первого админа

4. **Настройте переменные окружения:**

```bash
cp .env.local.example .env.local
```

Отредактируйте `.env.local`:

```env
NEXT_PUBLIC_SUPABASE_URL=https://your-project.supabase.co
NEXT_PUBLIC_SUPABASE_ANON_KEY=your-anon-key
PERPLEXITY_API_KEY=your-perplexity-key (опционально)
```

5. **Запустите проект:**

```bash
npm run dev
```

6. **Откройте браузер:**

```
http://localhost:3000
```

## Использование

### Для администратора

1. **Вход в систему:**
   - Используйте логин и пароль админа, созданного в Supabase

2. **Создание учеников:**
   - Перейдите во вкладку "Админ-панель"
   - Нажмите "+ Добавить ученика"
   - Заполните форму:
     - Логин (уникальный, только буквы, цифры, подчеркивание)
     - Полное имя
     - Пароль (можно сгенерировать автоматически)
   - Сохраните данные для передачи ученику

3. **Управление учениками:**
   - Просмотр списка всех учеников
   - Удаление учеников (кроме админов)
   - Просмотр даты регистрации

### Для ученика

1. **Вход в систему:**
   - Получите логин и пароль от администратора
   - Перейдите на сайт
   - Введите свои credentials

2. **Работа с системой:**
   - Все разделы доступны через верхнюю навигацию
   - Данные автоматически сохраняются в базу данных
   - Каждый ученик видит только свои данные

### Расписание

1. Нажмите "+ Добавить"
2. Заполните информацию о занятии
3. Расписание отображается по дням недели

### Домашние задания

1. Создайте новое задание
2. Укажите срок выполнения и приоритет
3. Отмечайте выполненные задания галочкой
4. Просроченные задания подсвечиваются красным

### Оценки

1. Добавьте оценку с указанием типа работы
2. Система автоматически рассчитает средний балл
3. Просматривайте статистику по предметам

### Отчеты по занятиям

1. Сначала создайте расписание
2. Выберите предмет из расписания
3. Опишите пройденный материал
4. Отметьте посещаемость

### AI-Ассистент

1. Задайте вопрос в чате
2. Получите помощь с учебой
3. История чата сохраняется автоматически

## Безопасность

### Row Level Security (RLS)

Все таблицы защищены RLS политиками:
- Ученики видят **только свои** данные
- Админы видят **все** данные
- Невозможно изменить чужие записи

### Аутентификация

- Пароли хешируются Supabase
- Сессии управляются через защищенные cookies
- Middleware защищает все страницы от неавторизованного доступа

### Best Practices

1. Используйте сложные пароли
2. Не коммитьте `.env.local` в Git
3. Регулярно проверяйте логи Supabase
4. Делайте backup базы данных

## Миграция с LocalStorage

**ВАЖНО:** Текущие компоненты (Schedule, Homework, Grades, Reports, AIAssistant) все еще используют localStorage. Для полной функциональности в многопользовательском режиме их нужно мигрировать на Supabase API.

### Статус миграции:

- ✅ Аутентификация
- ✅ Админ-панель
- ✅ База данных
- ⏳ Schedule component
- ⏳ Homework component
- ⏳ Grades component
- ⏳ Reports component
- ⏳ AI Assistant

Миграция будет выполнена в следующих коммитах.

## Production Deployment

### Vercel (рекомендуется)

1. Push в GitHub
2. Импортируйте проект в Vercel
3. Добавьте environment variables:
   - `NEXT_PUBLIC_SUPABASE_URL`
   - `NEXT_PUBLIC_SUPABASE_ANON_KEY`
   - `PERPLEXITY_API_KEY`
4. Deploy

### Supabase настройки для production

1. В Supabase перейдите в **Authentication** → **URL Configuration**
2. Добавьте production URL в **Site URL**
3. Добавьте `https://your-domain.com/**` в **Redirect URLs**

## Устранение проблем

### Не могу войти

- Проверьте credentials (логин, не email)
- Убедитесь, что пользователь существует в таблице `students`
- Проверьте, что Supabase проект активен

### Ошибки с базой данных

- Убедитесь, что все таблицы созданы
- Проверьте RLS политики
- Посмотрите логи в Supabase Dashboard

### Компоненты не работают

- Текущие компоненты используют localStorage
- Дождитесь миграции на Supabase API
- Или мигрируйте самостоятельно
